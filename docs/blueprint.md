# **App Name**: FFM

## Core Features:

- Interactive Music Player: Stream tracks and albums with play/pause, skip, and volume controls, creating an engaging listening experience.
- Dynamic Portfolio Gallery: Display projects in a visually appealing, filterable gallery format.
- Editable 'About' Section: An interface to modify the artist's biography and press releases easily.
- Custom Content Management System (CMS): Allows the artist to seamlessly update website content, including music, projects, and bio, without coding.
- AI-Powered Content Suggestion Tool: Leverages generative AI to provide suggestions for bio updates and project descriptions based on the artist's current work and style. The LLM acts as a tool in suggesting optional marketing hooks to the user.
- Fluid Page Transitions: Implement smooth, engaging animations for page transitions to enhance user experience.
- Contact Form: Provide an easy way for fans and industry professionals to reach out.

## Style Guidelines:

- Primary color: Deep charcoal (#333333) to create a sophisticated dark theme.
- Background color: Dark gray (#292929) with minimal saturation to keep the focus on content.
- Accent color: Warm amber (#FFB300) for highlights, calls to action, and interactive elements.
- Headline font: 'Belleza' sans-serif for headlines; body font: 'Alegreya' serif for body text, lending an elegant and artistic flair.
- Use minimalist, line-based icons with amber accents to maintain a clean and modern aesthetic.
- Implement a responsive, grid-based layout to ensure optimal viewing experience across devices.
- Incorporate subtle, fluid animations for transitions and interactions to add depth and engagement without being distracting.
